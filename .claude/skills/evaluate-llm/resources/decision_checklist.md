# LLM 选型五步决策 Checklist（打印友好版）

## Step 1：任务画像
- [ ] 任务形态：chat / RAG / agent / batch / realtime
- [ ] 关键能力：推理 / 代码 / 长文 / 多模态 / 工具调用 / 中文
- [ ] 硬约束：预算上限 ___/月；p95 延迟 ___s；并发 ___QPS
- [ ] 合规：数据出境？私有化？行业资质？

## Step 2：Benchmark 初筛（砍 80%）
- [ ] 选定 1-3 个**与任务直接相关**的 benchmark（不看综合榜）
- [ ] 记录候选模型在这些 benchmark 的分数
- [ ] 候选池收敛到 2-3 个

## Step 3：自建 eval set 实测
- [ ] 准备 50-200 条真实样本（典型 60% + 边界 30% + 已知失败 10%）
- [ ] 写好 rubric 或 expected output
- [ ] 跑 LLM-as-judge（judge 用更强的模型）
- [ ] 人工抽检 20%
- [ ] 记录失败模式聚类

## Step 4：工程 & 成本核算
- [ ] 算月度 TCO：`cost_calculator.py` 跑一下
- [ ] 测 p95 TTFT 是否满足
- [ ] 确认 rate limit、region、SLA
- [ ] 评估数据主权与合规风险

## Step 5：灰度 & A/B
- [ ] 5% 流量灰度
- [ ] 监控：任务完成率、CSAT、拒答率、成本
- [ ] 2 周观察期
- [ ] 决策：全量 / 回滚 / 多模型路由
