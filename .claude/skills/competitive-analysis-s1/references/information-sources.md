## How to Use This Directory

### Weekly Routine

**Monday**: Check VC blogs for weekend publications
**Tuesday-Thursday**: Browse Hugging Face daily papers, GitHub trending
**Friday**: Review Product Hunt weekly digest, update terminology database
**Weekend**: Deep dive into one selected long-form article or paper

### When Starting New Research

1. **Business context** (30 min): Check recent VC posts about the domain
2. **Technical frontier** (45 min): Search Hugging Face papers + GitHub repos
3. **Product landscape** (30 min): Product Hunt + specialized AI tool directories
4. **Documentation** (45 min): Read relevant framework docs (LangChain/LlamaIndex)

### Organizing Your Findings

Create a simple bookmark structure:
```
Competitive Analysis/
├── Business Layer/
│   ├── VC Insights/
│   ├── Founder Perspectives/
│   └── Market Maps/
├── Technology Layer/
│   ├── Papers/
│   ├── Benchmarks/
│   └── Model Comparisons/
└── Engineering Layer/
    ├── Open Source Projects/
    ├── Framework Docs/
    └── Technical Blogs/
```
