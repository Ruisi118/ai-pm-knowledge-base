## Fill Instructions

When populating this template:

1. **Overview**: Write for clarity, not impressiveness. If the user couldn't explain the overview to a friend, simplify it.

2. **Core Mental Models**: Each model should be self-contained — readable without the others. The "Connects to" field is what creates the map structure.

3. **Disagreements**: Be genuinely balanced. If you catch yourself favoring one side, explicitly strengthen the other. The user needs to understand the debate, not pick the "right" answer.

4. **Self-Assessment**: Be honest but constructive. Frame gaps as "areas to develop" not "things you got wrong." Reference specific moments from the Q3 interaction.

5. **Limitations**: This section is critical. Do not soften it. The user's long-term learning depends on accurate calibration of what they know vs. don't know.

6. **Next Steps**: Be specific. "Read more about X" is useless. "Read Chapter 3 of [specific book] because it covers the connection between Model 2 and Model 4 that you found unclear" is actionable.
