# AI PM 能力要求总结

> 基于 LiblibAI「AI垂类策略产品」JD 及阿里千问 AI 产品实习面经整理

---

## 1. AI 技术理解力

- 理解大模型核心概念：Transformer、预训练、SFT、RLHF/RLAIF 的区别与作用
- 理解 prompt engineering、system prompt、RAG、Agent、上下文窗口等产品侧技术概念
- 熟悉 AIGC 技术（文生图/视频：Stable Diffusion、Midjourney 等）
- 能判断问题来源：模型能力 vs 检索 vs prompt vs 产品策略

## 2. 评估体系设计能力

- 设计可量化的产品指标，将模型效果（美学质量、语义对齐等）拆解为可衡量的指标
- 构建多模态评估框架，包括自动化指标 + Human-in-the-Loop 流程
- 构建和维护 Testset，覆盖核心场景与边界风险
- 理解人工评估与算法指标的互补关系

## 3. 数据驱动与分析能力

- 能用 SQL 进行数据探索与指标追踪
- 通过数据分析识别瓶颈与优化机会
- 理解核心数据指标（留存、满意度等）及其冲突时的取舍逻辑
- 能设计验证实验，证明产品改动的有效性

## 4. RL 奖励机制与模型迭代

- 设计 RL 奖励模型的数据采集策略与标注规范
- 确保奖励信号对齐用户价值与商业目标
- 基于评估数据制定模型迭代路线图，推动模型能力转化为产品功能

## 5. 产品感知与设计能力

- 对生成效果有敏感度（审美判断力）
- 理解 Chat 产品的核心价值与边界（vs 搜索、vs Agent、vs 工具型产品）
- 能做意图识别与回复策略设计（多意图、模糊表达场景）
- 理解记忆系统设计（短期 vs 长期，该记什么、不该记什么）

## 6. 跨职能协作与沟通

- 与模型团队、业务团队紧密协作，对齐目标
- 向不同受众（技术/非技术）解释复杂概念
- 建立高效的用户反馈收集机制，将反馈转化为可执行需求

## 7. 加分项

- 平面设计 / 品牌视觉领域知识
- 创业经历，能在高不确定性环境中推动项目
- 流畅的英文书面与口头沟通
- 竞品分析能力（横向对比各 AI 产品的差异与短板）

---

**一句话总结：AI PM = 技术理解力 x 评估体系设计 x 数据驱动 x 产品感知 x 跨团队沟通，核心差异化在于"能定义什么是好的模型效果，并推动它落地为用户价值"。**
